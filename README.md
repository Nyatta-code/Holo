# Holo Launcher 2.0

لانشر أندرويد بطراز Holo (أندرويد 4).

## الميزات
- **صفحات بالسحب** (1 إلى 7)، شبكة قابلة للتغيير (4×4 حتى 6×6)، ومؤشر صفحات Holo.
- **ودجت**: تبويب Widgets في الدرج (أو ضغطة مطوّلة على مكان فاضي ← Widgets).
- **الدرج**: تبويبان Apps / Widgets، بحث فوري، Enter يفتح أول نتيجة أو يبحث في الويب.
- **ضغطة مطوّلة** على أيقونة أو ودجت: Move / Remove / App info. في الدرج: Add to home screen.
- **الإعدادات**: حجم الأيقونات والخط، عدد الأعمدة والصفوف والصفحات، تأثير الانتقال، الدوك، خلفية متحركة...
- **الخلفيات**: 8 خلفيات بألوان Holo الأصلية (أزرق، بنفسجي، أخضر، برتقالي، أحمر...).
- **شاشة القفل**: حلقة Holo (اسحب القفل للخارج). تُفعَّل من الإعدادات، وتحتاج إذن "العرض فوق التطبيقات".
- **قائمة Debug**: في الإعدادات اضغط **Build number** سبع مرات. فيها FPS، الذاكرة، سجل، وأدوات.
- **الأداء**: الأيقونات تُرسم مسبقاً في خيط خلفي، والدرج RecyclerView، وكل شيء على bitmaps جاهزة.

## البناء
ارفع المجلد إلى GitHub وسيبني **GitHub Actions** ملف APK تلقائياً (تبويب Actions ← HoloLauncher-apk).
أو افتحه في Android Studio واضغط Run.
