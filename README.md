# Holo Launcher

لانشر أندرويد بطراز Holo (أندرويد 4): ثيم داكن، لمسات سماوية `#33B5E5`، ساعة رفيعة كبيرة، شريط بحث، دوك من 5 خانات، ودرج تطبيقات ببحث فوري.

## التشغيل
1. افتح المجلد `HoloLauncher` في **Android Studio** (Hedgehog أو أحدث).
2. انتظر مزامنة Gradle (يحمّل Gradle 8.2 تلقائياً).
3. وصّل جوالك (تصحيح USB) أو شغّل محاكي، ثم **Run**.
4. اضغط زر الهوم ← اختر **Holo Launcher** ← **Always**.

لبناء APK جاهز: `Build > Build Bundle(s) / APK(s) > Build APK(s)`.

## الميزات
- **الشاشة الرئيسية**: خلفيتك تظهر خلف الواجهة. ضغطة مطوّلة على أي مكان فاضي = تغيير الخلفية.
- **الدوك**: الهاتف، الرسائل، زر الدرج (وسط)، المتصفح، الكاميرا. يستخدم تطبيقاتك الافتراضية تلقائياً.
- **درج التطبيقات**: مرتب أبجدياً، بحث فوري، زر Enter يفتح أول نتيجة.
- **ضغطة مطوّلة على تطبيق**: معلومات التطبيق / إزالة.
- يتحدّث تلقائياً عند تثبيت أو حذف تطبيق.

## الملفات
- `MainActivity.java`: الشاشة الرئيسية والدوك والدرج
- `AppAdapter.java` / `AppInfo.java`: قائمة التطبيقات والبحث
- `res/layout/`: واجهات الشاشة والعنصر
- `res/values/styles.xml`: ثيم Holo مع خلفية الجهاز
